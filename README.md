# 📚 Flux – Personal Expense Tracker & Budget Planner (PWA)

A progressive web expense tracking and budget planning application that can be installed on macOS, Windows, mobile devices, and used directly in web browsers.

## 🛠️ Tech Stack

- React.js (TypeScript)
- Tailwind CSS (fully responsive for all devices)
- Chart.js (interactive graphs and charts for data analysis)
- Dexie.js (offline database that works on the user's device without internet)

---

## ✨ Features

- Installable web app that works both online and offline (PWA)
- No server-side database required; no registration needed
- Data is stored locally on the user's device
- Track expenses and income with monthly summaries using graphs and charts
- Budget planning and expense tracking system
